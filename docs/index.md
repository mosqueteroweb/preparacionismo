# Wiki Preparacionismo

Recopilación de recursos, técnicas y materiales para la [preparación](https://es.wikipedia.org/wiki/Supervivencia) ante situaciones concretas: inundaciones, incendios, nevadas y confinamientos (virus u otras causas).

## Escenarios

- 🌊 **Inundación** — qué hacer antes, durante y después de una crecida.
- 🔥 **Fuego** — prevención, evacuación y extinción de incendios.
- ❄️ **Nevadas** — cortes, aislamiento y frío.
- 🦠 **Virus / Confinamiento** — sobrevivir en casa 72 h.
- 🔌 **Apagón** — luz, nevera, comunicaciones y calefacción sin red.

## Temas transversales

- 💧 **Agua** — almacenamiento, potabilización y filtrado.
- 🥫 **Alimentación** — reservas y huerta urbana.
- ⚕️ **Salud** — primeros auxilios, botiquines y manuales.
- 📡 **Comunicaciones** — walkies, radioafición y frecuencias.
- 📄 **Documentación** — manuales y PDF de referencia.
- 🔦 **Energía / luz** — iluminación y energía de respaldo.
- 🛠️ **Herramientas** — nudos, ganzúas y bricolaje de emergencia.
- 📦 **Otros** — lo que no encaja arriba.

Usa el buscador o el menú lateral para navegar. Para añadir o editar contenido se crea o modifica un archivo `.md` en la carpeta `docs/` del repositorio; la web se actualiza sola con GitHub Actions.

Esta web es estática (MkDocs), alojada en GitHub Pages.
