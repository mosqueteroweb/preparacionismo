# Heridas y hemorragias


Resumen del manual "Primeros auxilios y supervivencia en el medio natural".

**Actuación ante hemorragia externa:**
1. Presión directa sobre la herida.
2. Elevación del miembro.
3. Presión sobre la arteria principal del miembro.
4. Torniquete (como último recurso).

**Ante hemorragia interna:** tumbado boca arriba, cabeza a un lado; no dar de beber; cubrir con manta; traslado MUY URGENTE.

**Heridas simples o superficiales:** limpiar manos/instrumental/herida con agua o solución antiséptica; gasas de dentro a fuera; antiséptico no coloreado (clorhexidina); apósito estéril.

**Heridas graves:** no explorar para quitar cuerpos extraños; apósito estéril; vendaje; inmovilizar. En cráneo/tórax/abdomen: no retirar objetos clavados, tapar herida de forma impermeable (tórax), no reponer vísceras (abdomen), cubrir húmedo y fajar.

**Qué NO usar nunca:** algodón/servilletas de papel, alcohol/yodo/lejía, pomadas con antibióticos.
